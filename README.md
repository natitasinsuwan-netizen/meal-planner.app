# 🥗 Meal • Random — Smart Meal Planner Web App

A warm pastel responsive web application for meal planning, daily energy tracking (BMR / TDEE calculations), keyword-based recipe filtering, and random meal recommendations.

## ✨ Features
- **Responsive Design**: Optimized for mobile phones (iOS & Android), tablets, and desktop displays.
- **Dynamic Energy Calculation**: Mifflin-St Jeor TDEE formula calculated from user's biological sex, birthday (date of birth), weight (kg), height (cm), and exercise frequency.
- **Admin Control Panel**: Full access for `natitasinsuwan@gmail.com` to view catalog recipes, edit recipe details (`✏️ Edit Recipe`), delete dishes, and publish new custom meals (`➕ Add New Meal`).
- **Keyword Meal Filtering**: Filter recipes by Cuisine Country, Cooking Method, Carbs, and Protein sources.
- **Daily Energy Tracking**: Real-time Bento calorie cards tracking Energy Need, Consumed, and Remaining balance.

## 🚀 Running Locally
Open `index.html` in any web browser or serve via Python:
```bash
python -m http.server 8080
```
